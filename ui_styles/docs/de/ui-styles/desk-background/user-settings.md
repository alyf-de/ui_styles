# Persönliche Schreibtisch-Farbe

Wenn ein System-Manager **Desk Background** aktiviert und *Benutzern erlauben, eine eigene Farbe zu wählen* auf **Schreibtisch-Hintergrund Einstellungen** eingeschaltet hat, können Sie Farbe und Stärke selbst wählen.

1. **Nutzer** öffnen (eigener Nutzerdatensatz).
2. Tab *Einstellungen* → Bereich *Einstellungen für den Schreibtisch*.
3. *Schreibtisch-Farbe* (unter *Schreibtisch-Design*) - Farbe wählen oder leer lassen für die Seitenvoreinstellung.
4. *Schreibtisch-Farbstärke* - **Sanft** oder **Kräftig**, oder leer lassen für die Seitenvoreinstellung.

Speichern. Der Schreibtisch leert den Cache und wird neu geladen, wenn sich Ihre effektive Farbe oder Stärke ändert.

Sind die Felder nicht sichtbar, ist die Funktion seitenweit deaktiviert oder die persönliche Wahl ist nicht erlaubt.

Siehe auch: [Seiteneinstellungen](/app/docs/de/ui-styles/desk-background/site-settings).
