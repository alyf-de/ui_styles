# Schreibtisch-Hintergrund

Subtiler Schreibtisch-Hintergrund, um Test- und Staging-Systeme von Produktion zu unterscheiden. Die Farbe ist nur eine visuelle Hilfe - prüfen Sie zusätzlich URL oder den Hostname der Seite.

Die Funktion ist **standardmäßig aus**. Ein System-Manager muss sie auf **Schreibtisch-Hintergrund Einstellungen** aktivieren, bevor ein Farbton erscheint.

## Farbhierarchie

1. **Deaktiviert** - Frappe-Standardfarben (Standard nach Installation)
2. **Standard** - Frappe-Standardfarben, wenn aktiv, aber keine Tint-Voreinstellung gewählt
3. **Seitenvoreinstellung** - System-Manager auf **Schreibtisch-Hintergrund Einstellungen**
4. **Persönliche Voreinstellung** - optional auf **Nutzer**, wenn *Benutzern erlauben, eine eigene Farbe zu wählen* aktiv ist

## Anleitungen

- [Seiteneinstellungen](/app/docs/de/ui-styles/desk-background/site-settings) - **Schreibtisch-Hintergrund Einstellungen**
- [Persönliche Schreibtisch-Farbe](/app/docs/de/ui-styles/desk-background/user-settings) - **Nutzer**-Feld unter *Schreibtisch-Design*

Beim Speichern der eigenen *Schreibtisch-Farbe* oder von **Schreibtisch-Hintergrund Einstellungen** wird der Cache geleert und der Schreibtisch neu geladen.
