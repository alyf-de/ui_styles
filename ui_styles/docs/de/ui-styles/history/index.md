# Verlauf

Ein Uhr-Symbol in der Desk-Navigationsleiste öffnet ein Menü der zuletzt besuchten Seiten. Die Liste mischt Seiten aus dieser Browser-Sitzung mit **Route History** des angemeldeten Benutzers. Die aktuelle Seite entfällt. Jede Route erscheint einmal, die neueste zuerst.

Die Funktion ist **standardmäßig aus**. Ein System-Manager muss *Aktiviert* in **Verlauf Einstellungen** einschalten, bevor das Symbol erscheint.

*Filter* oben im Menü kann Einstellungen, Arbeitsbereiche, Berichte, Listen und Belege ausblenden. Die Auswahl bleibt in diesem Browser gespeichert. Das X am Filter-Chip schaltet alle Gruppen wieder ein. Ausblenden löscht keine **Route History**.

## Anleitungen

- [Seiteneinstellungen](/app/docs/de/ui-styles/history/site-settings) - **Verlauf Einstellungen**

Beim Speichern von **Verlauf Einstellungen** wird der Cache geleert. Desk hart neu laden, um Änderungen anzuwenden.
