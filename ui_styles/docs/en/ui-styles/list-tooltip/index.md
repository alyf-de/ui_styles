# List Tooltip

Hover an info icon in a list row to preview chosen fields of that document without opening it. For each **DocType** you choose which fields appear as label / value rows (header) and which one appears as a text block (body), for example an email-style preview for **Communication**.

Optionally enable *Comment Preview* to show the latest **Comment** or **Communication** when hovering the comment count on any list.

The feature is **off by default**. A System Manager must turn on *Enabled* on **List Tooltip Settings**, then either add at least one configuration row and/or enable *Comment Preview*.

Saving **List Tooltip Settings** clears cache. Hard-refresh Desk to apply changes.
