# List Tooltip

Hover an info icon in a list row to preview chosen fields of that document without opening it. For each **DocType** you choose which fields appear as label / value rows (header) and which one appears as a text block (body), for example an email-style preview for **Communication**.

The feature is **off by default**. A System Manager must enable *Enabled* on **List Tooltip Settings** and add at least one configuration row before any icon appears.

## Guides

- [Site settings](/app/docs/en/ui-styles/list-tooltip/site-settings) - **List Tooltip Settings**
- [Example: Communication](/app/docs/en/ui-styles/list-tooltip/example-communication) - email-style preview

Saving **List Tooltip Settings** clears cache. Hard-refresh Desk to apply changes.
