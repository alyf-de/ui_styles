# Desk Background

Apply a subtle Desk background tint so test and staging systems are easy to tell apart from production. Colour is a visual aid only - also check the site URL or hostname.

The feature is **off by default**. A System Manager must enable it on **Desk Background Settings** before any tint appears.

## How colours are chosen

1. **Disabled** - stock Frappe colours (default after install)
2. **Standard** - stock Frappe colours when enabled but no tint preset selected
3. **Site preset** - set by a System Manager on **Desk Background Settings**
4. **Personal preset** - optional on **User** when *Allow users to choose their own colour* is enabled

## Guides

- [Site settings](/app/docs/en/ui-styles/desk-background/site-settings) - **Desk Background Settings**
- [Personal desk colour](/app/docs/en/ui-styles/desk-background/user-settings) - **User** field below *Desk Theme*

Saving your own *Desk Colour* or **Desk Background Settings** clears cache and reloads Desk.
