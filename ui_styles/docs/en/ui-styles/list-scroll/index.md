# List Scroll

Dense Desk list layout: content-sized columns and one shared horizontal scrollbar in the list header that pans all row column tracks. Optional sticky column header, floating paging bar, and sticky front columns. Configure site Defaults and optional per-DocType overrides on **List Scroll Settings**.

The feature is **off by default**. A System Manager must enable *Dense List Layout* (in Defaults or in a DocType override) before lists change.

## Guides

- [Site settings](/app/docs/en/ui-styles/list-scroll/site-settings) - **List Scroll Settings**

Saving **List Scroll Settings** clears cache. Hard-refresh Desk to apply changes.
